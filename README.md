# SAFARSYNC
A blockchain-secured travel assistant featuring wallet-less data integrity, integrating interactive maps and AI to provide seamless navigation and personalized, real-time trip support.
<br/>
<strong>🌟 Key Features: 🌟</strong> <br/>
⛓️ Wallet-less Blockchain: Uses backend signing to ensure data integrity and security without requiring users to manage complex crypto wallets. <br/>
🗺️ Smart Navigation: Integrates high-performance maps for real-time wayfinding, helping travelers navigate unfamiliar destinations with ease. <br/>
🤖 AI Travel Guide: Provides intelligent, context-aware assistance and personalized recommendations. <br/>
🛡️ Immutable Records: Leverages decentralized storage to create a tamper-proof history of hotels, workshops, and events. <br/>
🚀 Frictionless UX: Bridges the gap between Web2 simplicity and Web3 security, offering a smooth, optimized interface. <br/>
☁️ Seamless Integration: Combines mapping APIs and LLMs into a unified architecture for a cohesive, all-in-one travel experience. <br/>
🛠 <strong>Tech Stack</strong><br/>
Frontend: Flutter, CSS.<Br/>
Backend Setup: PostgreSQL,Nodejs,Expressjs.<br/>
Blockchain: Ethers, Solidity, Infura.<br/>
